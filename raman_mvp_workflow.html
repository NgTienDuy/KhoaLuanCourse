How to read this workflow

Each node = one task with ID, estimated hours, label, and 1-line description. Tasks within the same layer can usually run in parallel. Tasks in later layers depend on earlier layers (the convergence). Solid borders = must-have; dashed borders = optional. Red-tinted shadow = critical path (cannot skip without breaking downstream).

  • Total estimated effort: ~120 hours over 14 days = ~8.5 h/day. Realistic for a focused MVP sprint.
  • Critical path (red): T02 → T03 → T10 → T11 → T15 → T17 → T18 → T26 → T33. If any of these slip, the whole project slips.
  • Day-7 gate (T17): If your model isn't hitting baseline by Day 7, STOP and simplify. Better to ship a smaller working MVP than a broken big one.
  • Optional tier (T08, T28, T29, T30, T31): Only attempt if Day 7 went smoothly. T28 (Streamlit) is highest-value optional for thesis defense.
